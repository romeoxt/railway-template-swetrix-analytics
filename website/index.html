Five services. One public URL.

Only the gateway is exposed. API, frontend, Redis, and ClickHouse talk over Railway private networking.

  1. Gateway

    Nginx routes / to the dashboard and /backend/ to the API. This repo.

  2. Swetrix API + FE

    Official swetrix/swetrix-api and swetrix-fe v5.4.1 images.

  3. ClickHouse + Redis

    Events on a persistent volume. Redis for caching. Both private.

Custom events

Performance

Volume-backed

Secure signup
